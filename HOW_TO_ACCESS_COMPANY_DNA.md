# 🎯 Cách vào Company DNA (30 giây)

## Bước 1: Mở Dashboard
```
http://localhost:3000
```

## Bước 2: Click button góc trên phải

```
┌──────────────────────────────────────────────┐
│  Dashboard                            [Buttons] │
│                                                  │
│                    👇 CLICK ĐÂY                 │
│            [✨ Company DNA]                     │
│               (Button màu xanh lá)              │
└──────────────────────────────────────────────┘
```

## Bước 3: Điền form

**4 phần cần điền:**
1. ✅ Thông tin cơ bản (tên công ty, ngành nghề)
2. ✅ Sản phẩm (loại, tính năng, điểm mạnh)
3. ✅ Khách hàng (ai, vấn đề gì, mục tiêu gì)
4. ✅ Thương hiệu (màu sắc, giọng điệu)

## Bước 4: Lưu
Click nút **"Save Company DNA"** ở dưới cùng

---

## ⚡ Không thấy button?

**Cách khác:** Vào trực tiếp
```
http://localhost:3000/settings/company
```
