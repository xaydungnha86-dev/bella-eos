# 🚀 Creative Intelligence Engine v3 - Migration Guide

## Overview

Creative Intelligence Engine v3 introduces a revolutionary 4-layer architecture that transforms prompt generation from **template concatenation** to **AI-powered creative reasoning**.

---

## 🏗️ Architecture Comparison

### ❌ Old Architecture (v2)

```
CEO Objective
    ↓
Parse Domain (if/else rules)
    ↓
Extract Copywriter (regex)
    ↓
Template Assembly
    ↓
String Concatenation
    ↓
Prompt
```

**Problems:**
- ✗ No semantic understanding
- ✗ Hardcoded domain templates
- ✗ Copywriter headline copy-paste
- ✗ Rule-based, not AI-reasoned

---

### ✅ New Architecture (v3)

```
CEO Objective
    ↓
Layer 1: Business Context Aggregation
    ↓
Layer 2: Creative Reasoning (LLM)
    ↓
Layer 3: Prompt Composition (LLM)
    ↓
Layer 4: Model Adaptation
    ↓
Model-Specific Prompts (Imagen/DALL-E/Flux)
```

**Benefits:**
- ✓ Deep AI understanding
- ✓ Domain-agnostic (works with ANY industry)
- ✓ Synthesized headlines (not copied)
- ✓ LLM-powered creative strategy

---

## 📊 Key Differences

| Feature | v2 (Old) | v3 (New) |
|---------|----------|----------|
| **Domain Detection** | `if (objective.includes('spa'))` hardcoded | LLM understands from context |
| **Headline Generation** | Copy from Facebook post | LLM creates NEW poster-optimized headline |
| **Prompt Strategy** | Template assembly | LLM composes visual narrative |
| **Model Support** | 3 hardcoded formats | Adapter pattern (infinitely extensible) |
| **Explainability** | None | Full reasoning chain |
| **Learning** | Static rules | Can integrate performance feedback |

## ⚠️ Breaking Changes

### 1. Headline No Longer Copied from Copywriter

**Old Behavior:**
```typescript
dynamicHeadline = extractHeadlineFromCopywriter(copywriterContent);
// Result: "5 sai lầm khiến Spa mất khách"
```

**New Behavior:**
```typescript
creativeBrief.posterHeadline = await LLM.synthesizeHeadline(context);
// Result: "AI VẬN HÀNH SPA THẾ HỆ MỚI"
```

**Migration:** Update any code that expects headline to match copywriter content.

---

### 2. Domain Templates Removed

**Old Behavior:**
```typescript
if (objective.includes('spa')) {
  return spaTemplate;
}
```

**New Behavior:**
```typescript
// LLM understands domain from full business context
creativeBrief = await CreativeDirectorAgent.reason(businessContext);
```

**Migration:** Remove any hardcoded domain checks.

---

### 3. Response Structure Changed

**Old Response:**
```json
{
  "success": true,
  "imageUrl": "...",
  "provider": "google-imagen"
}
```

**New Response:**
```json
{
  "success": true,
  "imageUrl": "...",
  "provider": "google-imagen",
  "creativeBrief": { ... },
  "reasoning": [ ... ],
  "pipelineVersion": "3.0.0"
}
```

**Migration:** Update response parsing code.
