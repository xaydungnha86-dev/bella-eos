## 🔄 What Changed

### Routing Behavior

**BEFORE (v2):**
```
/api/ai/generate-image
  ↓
Template-based generation
  ↓
Hardcoded domain logic
  ↓
Copy headline from Facebook
```

**AFTER (v3 with feature flag):**
```
/api/ai/generate-image
  ↓
Check CREATIVE_INTELLIGENCE_VERSION env var
  ↓
Delegate to /api/ai/generate-image-v3
  ↓
4-layer AI reasoning pipeline
  ↓
Synthesized poster headline
```

### API Response Structure

**v2 Response:**
```json
{
  "success": true,
  "imageUrl": "...",
  "provider": "imagen-3",
  "model": "imagen-3.0-generate-002",
  "prompt": "..."
}
```

**v3 Response (NEW):**
```json
{
  "success": true,
  "imageUrl": "...",
  "provider": "imagen-3",
  "model": "imagen-3.0-generate-002",
  "creativeBrief": {
    "headline": "AI VẬN HÀNH SPA THẾ HỆ MỚI",
    "campaignGoal": "Drive demo bookings from spa owners...",

    "confidence": 0.75
```
